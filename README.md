# Database Plugin для LinCtrl Desktop

Скопируйте каталог `database.linctrl` в `plugins` рядом с исполняемым файлом LinCtrl Desktop. Включите плагин в разделе «Плагины» и войдите на сервер с установленным Host Database Plugin.

Страница показывает версию серверного плагина, списки и отдельные записи пользователей, ролей и истории. Списки пользователей и истории разбиты на страницы. Администратору доступны создание, изменение и удаление пользователей и записей истории. Роли доступны для чтения.

Для запросов используется `Session.request` в LinCtrl Desktop. Приложение само добавляет JWT выбранного сервера.
