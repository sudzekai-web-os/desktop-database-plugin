# База данных для LinCtrl Desktop

Скопируйте содержимое каталога `plugin` в папку `database.linctrl` внутри `plugins` рядом с LinCtrl Desktop. Включите плагин в разделе «Плагины» и войдите на сервер с соответствующим серверным плагином.

Пользователи, роли и история изменений открываются на отдельных страницах. Администратор может создавать и изменять пользователей, блокировать их и редактировать историю. Роли доступны для чтения.

Запросы выполняет `PluginRequest` из модуля `linctrl`. Он использует JWT текущей сессии и разбирает JSON-обёртку серверного ответа.
